# 🦅 HarpyX

**VPN-клиент для Android на базе Mihomo.**

Добавь подписку HarpyNet, выбери страну и подключись. Основные настройки под рукой на одной панели, а между «Умным обходом» и «Полным VPN» можно переключаться прямо оттуда.

## ✨ Что умеет HarpyX

- 🔗 **Импорт подписки** по ссылке или QR-коду.
- 🌍 **Выбор страны** из серверов, доступных в твоей подписке.
- ⚡ **Проверка задержки** серверов перед подключением.
- 📊 **Статистика подписки** со сроком действия и расходом трафика в ГБ или ТБ.
- 🔄 **Обновление профиля** прямо с главной панели.
- 🛡️ **Проверка сервисов** вроде Google, GitHub и YouTube внутри приложения.
- 🎨 **Настройка панели** с возможностью перемещать и скрывать карточки.
- 📱 **Интерфейс для телефона и планшета** с отдельной раскладкой в альбомной ориентации.
- 📰 **Новости и обновления** в разделе «О программе».

## 🧭 Какой режим выбрать

| Режим | Как работает |
| --- | --- |
| 🧠 **Умный обход** | Приложение следует правилам подписки. Одни сайты идут через VPN, другие открываются напрямую. |
| 🔒 **Полный VPN** | Трафик по умолчанию идёт через выбранный VPN-сервер. Исключения определяются конфигурацией. |

Страну можно поменять через **Панель → Изменить страну**. Рядом с кнопкой отображается флаг выбранного сервера.

## 📥 Как установить

Когда APK будет опубликован, его можно скачать в разделе [Releases](../../releases).

| Файл | Для какого устройства |
| --- | --- |
| `arm64-v8a` | Большинство современных телефонов и планшетов Android |
| `armeabi-v7a` | Устройства с 32-битной версией Android |
| `x86_64` | Android-устройства и эмуляторы на x86-64 |
| `universal` | Один APK для всех перечисленных архитектур. Подойдёт, если не знаешь, какой вариант выбрать |

## 🚀 Первое подключение

1. Установи APK и открой **HarpyX**.
2. Перейди в **Профили → Добавить профиль**.
3. Вставь ссылку на подписку HarpyNet или отсканируй QR-код.
4. Вернись на **Панель**, выбери страну и режим.
5. Нажми кнопку подключения. При первом запуске Android попросит разрешить VPN-подключение.

Когда список серверов или правила подписки изменятся, нажми круглую кнопку обновления рядом с профилем.

## 📰 Где посмотреть изменения

Открой **Инструменты → О программе → Что нового?**. Когда выйдет новая версия, список изменений можно открыть и в окне обновления. Последние загруженные новости доступны без интернета.
